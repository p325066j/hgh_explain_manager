# システム定義セクション

<system_overview> 
医療機関における検査・治療説明の効率化を図るPWAアプリケーションです。医師・看護師の説明業務を動画コンテンツで代替し、患者の待ち時間を活用した説明提供により、医療スタッフの業務負荷軽減と患者満足度向上を実現します。

# ⾮機能要件セクション 
<non_functional_requirements> 
<performance> 
- レスポンス時間の要件: 動画再生開始まで3秒以内、動画一覧表示まで1秒以内
- 同時接続数の要件: 同一医療機関内での同時利用（想定10-20台のタブレット）
- データ処理量の要件: 動画ファイルサイズ最大500MB、同時アップロード数最大5ファイル
- 動画再生性能: 1080p動画のスムーズな再生、バッファリング時間最小化
</performance> 
<security> 
- 認証・認可要件: 医療スタッフ向け管理機能の認証、患者向けは認証不要
- データ保護要件: 個人情報保護法遵守、動画データの暗号化保存
- コンプライアンス要件: 医療関連法規・法令の遵守、患者データの適切な管理
- アクセス制御: 医療機関内ネットワークからのみアクセス可能
</security> 
<scalability> 
- ⽔平スケーリング要件: 自施設専用のため大規模スケーリングは不要
- バックアップ要件: 動画データの定期バックアップ、メタデータの冗長化
- 災害復旧要件: ローカルバックアップからの復旧機能
- ストレージ拡張: 動画データ増加に対応したストレージ容量拡張
</scalability> 
<usability> 
- UI/UX要件: タブレット最適化UI、直感的な操作、大きなタッチターゲット
- アクセシビリティ要件: 字幕表示、高コントラスト表示、音声ガイダンス対応
- 多⾔語対応要件: 日本語・英語対応、将来的な他言語拡張可能性
- オフライン利用: ネットワーク切断時も基本機能が利用可能
</usability> 
<reliability>
- 可用性要件: 医療機関営業時間内（平日8:00-18:00）の99%可用性
- 障害対応: 単一障害点の排除、自動復旧機能
- データ整合性: 動画ファイルとメタデータの整合性保証
</reliability>
<maintainability>
- 保守性要件: 単一開発者による運用・保守が可能な設計
- 更新性要件: 動画コンテンツの簡単な追加・更新・削除
- ログ機能: 操作ログ、エラーログの記録・確認機能
</maintainability>
</non_functional_requirements>
